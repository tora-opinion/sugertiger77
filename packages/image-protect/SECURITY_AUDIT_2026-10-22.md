# `packages/image-protect` セキュリティ監査

2026-10-22 に、この作業ツリー内の Pages Functions、R2/KV 処理、画像アップロード経路を確認したで。

## 見つけて直した問題

### P1 — 署名URLを使って別の画像を取得できる

署名はURL中の画像IDで検証してたけど、R2から読むIDはルートパラメーターから取っていて、両者の照合がなかった。画像Aの署名URLを画像Bのパスに差し替えると、Bを取得できる状態やった。ルートIDも署名検証へ渡して一致を必須にした。

### P1 — アップロード本文の事前上限と実データ形式の確認がなかった

`formData()` が本文全体を読む前にサイズを制限しておらず、`Content-Type` の申告値だけで画像形式を受け入れてた。本文を設定上限（標準10 MiB、設定値は最大25 MiB）とmultipart用64 KiBの範囲で読み、単一のファイルだけを受理するようにした。JPEG/PNG/GIF/WebPのシグネチャと申告MIMEタイプが一致せなければ拒否する。

認証JSON本文にも8 KiBの上限を追加した。`MAX_FILE_SIZE`、レート上限、署名URL有効期間の異常値は安全な既定値へ戻す。

### P1 — レート制限が障害時に通過し、ログイン試行は制限されていなかった

KVの読み書きに失敗すると許可扱いになり、middleware側の例外処理も制限を迂回してた。KV障害時は503で拒否するよう変更し、ログインを5回/5分、画像管理・署名画像APIを100回/分で制限するようにした。アップロードとCDNの既存制限もKV障害時に通さへん。

### P2 — 内部エラーの詳細をAPI応答に返していた

アップロード、認証、画像取得、削除、一覧の失敗時に例外メッセージを返す経路を、汎用エラー応答へ置き換えた。

### P2 — 削除キーの確認だけでR2画像本体を取得していた

削除キーの確認にはメタデータだけあれば足りるため、画像本体の取得をR2の`head`相当へ変えた。画像一覧のlimitも1〜100に収める。

## 残る制約・未検証事項

- KVのカウント更新は読み取りと書き込みが別操作や。並行リクエストやKVの反映遅延で、短時間に設定数を超える可能性は残る。厳密な同時制御にはDurable Objectなど原子的なカウンターが要るで。障害時の通過は塞いだけど、この競合までは解消してへん。
- 画像判定は先頭シグネチャの確認までで、完全なデコード、寸法・総ピクセル数、GIFフレーム数までは検査してへん。異常な寸法を持つ画像が閲覧側のメモリを使い切る可能性は残る。
- CDNのReferer判定とUser-Agentによるボット判定は偽装可能で、Refererなしのアクセスは許可される。認可の仕組みとしては扱えず、現状どおりベストエフォートの対策や。
- CDN画像とビューアーは最大1時間、署名画像は最大5分のキャッシュ指定がある。削除後も既に取得済みのブラウザーキャッシュ等から表示される可能性がある。
- Cloudflare Pages上での実リクエスト、R2/KV接続、同時負荷、デプロイ後の挙動は確認してへん。デプロイもしてへん。

## 確認したこと

このコードでは、利用者のURLへサーバー側から接続する処理は見つからず、SSRFにつながる外部取得経路は確認できへんかった。R2キーへ使う画像IDも各取得・削除ルートで16桁の小文字16進数に限定されていて、パストラバーサル経路は確認できへんかった。

## Review fixes

- レート制限: KVカウンターの読み取り失敗は503で拒否し、書き込み失敗ではリクエストを通すようにした。KVの書き込み上限や競合時はカウントが漏れて、制限が弱まる可能性があるで。
- KVへの書き込みは許可したリクエストごとに試す。書き込み頻度を下げるとKV上のカウントが実際の試行数より小さくなるため、競合や書き込み上限による取りこぼしはベストエフォートの制約として記録した。
- 管理者認証: JSON本文は配列や`null`ではないオブジェクトで、空でない文字列の`password`を含む必要がある。不正な形は400で返す。
- `packages/image-protect/tests/security.test.mjs` に読み取り失敗、書き込み失敗、不正な認証JSONの確認を追加。
- `packages/image-protect` で `node --test --experimental-strip-types tests/security.test.mjs` — 7件成功。
- `packages/image-protect` で `..\..\node_modules\.bin\tsc.cmd --noEmit` — 成功。
